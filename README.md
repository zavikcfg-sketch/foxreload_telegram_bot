# Бот для продажи Telegram Stars и Premium

Автоматическая схема: клиент оплачивает → бот создаёт заказ у поставщика (FireLoot) →
поставщик сам доставляет товар → бот уведомляет клиента. Ручного участия в
обычной работе не требуется.

## Что нужно сделать перед запуском (один раз)

1. **Создать бота.** Написать [@BotFather](https://t.me/BotFather), команда `/newbot`,
   получить `BOT_TOKEN`.

2. **Подключиться к ЮKassa.** Зарегистрироваться на [yookassa.ru](https://yookassa.ru)
   как самозанятый или ИП (для приёма платежей от физлиц по закону нужен один из
   этих статусов — без регистрации ИП/самозанятости легально принимать оплату
   от клиентов нельзя). Получить `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`.
   В личном кабинете ЮKassa указать URL вебхука: `https://ВАШ_ДОМЕН/webhooks/yookassa`.

3. **Подключиться к FireLoot.** Написать [@firelootshop](https://t.me/firelootshop),
   сказать, что хотите продавать звёзды и Premium через API. Вам выдадут доступ
   в личный кабинет, где вы:
   - выпустите `FIRELOOT_API_KEY`;
   - включите направление Telegram;
   - увидите реальные адреса методов (базовый `FIRELOOT_BASE_URL` в этом проекте — placeholder,
     замените на настоящий из кабинета, если он будет отличаться);
   - увидите актуальный прайс — впишите его в `pricing.py` вместо примерных чисел;
   - настроите секрет для проверки подписи вебхуков (`FIRELOOT_WEBHOOK_SECRET`)
     и укажете адрес вебхука: `https://ВАШ_ДОМЕН/webhooks/fireloot`.

4. **Пополнить баланс FireLoot.** Перевод USDT (сеть TON) на выданный вам адрес.
   Минимально нужно покрыть стоимость одной поставки самого маленького пакета —
   это и есть единственные "вложения", избежать их технически нельзя: поставщик
   не может отгрузить товар с нулевого баланса. Как только пойдут первые продажи,
   можно пополнять баланс из вырученных денег, не добавляя своих.

5. **Узнать свой ADMIN_CHAT_ID** (куда бот будет слать предупреждения о низком
   балансе и сбоях доставки) — напишите [@userinfobot](https://t.me/userinfobot).

Заполните все эти значения в `.env` (скопируйте `.env.example` → `.env`).

## Запуск локально (для проверки)

```bash
pip install -r requirements.txt
python bot.py            # сам телеграм-бот (long polling)
# в отдельном терминале — веб-сервер для приёма вебхуков:
uvicorn bot:app --host 0.0.0.0 --port 8000
```

Для локальной проверки вебхуков понадобится туннель наружу, например `ngrok http 8000`,
и временно указать полученный `https://...ngrok...` адрес в кабинетах ЮKassa и FireLoot.

## Бесплатный/дешёвый хостинг для постоянной работы

Локальный компьютер для реальной продажи не годится — он должен работать 24/7.
Варианты, которые не требуют денег на старте:

- **Render.com** — бесплатный план для небольших сервисов (с ограничениями по
  времени работы, но для старта хватает).
- **Railway.app** — есть бесплатный пробный лимит, дальше недорого.
- **VPS за ~150-300 ₽/мес** (Timeweb, Beget, Selectel) — если бесплатных лимитов
  не хватит, это самый стабильный вариант; оплатить можно из первой же прибыли.

На любом из них нужно запустить оба процесса — `bot.py` (поллинг Telegram) и
веб-сервер `uvicorn bot:app` (приём вебхуков ЮKassa и FireLoot) — либо объединить
их в один процесс с помощью supervisor/systemd, либо использовать `aiogram`
в режиме вебхука вместо поллинга (более грамотно для сервера, но чуть сложнее
в настройке — могу дописать при необходимости).

## Кто и когда всё-таки нужен человеку

- Раз в какое-то время проверять, что баланс FireLoot не ушёл в ноль (бот сам
  пришлёт предупреждение в `ADMIN_CHAT_ID`, если он настроен).
- Отвечать в поддержку, если клиент напишет с вопросом напрямую боту (бот сейчас
  не обрабатывает произвольные сообщения вне сценария покупки).
- Раз в квартал платить налог с дохода как самозанятый/ИП — это не техническая,
  а юридическая обязанность, автоматизировать её нельзя.

## Важно про риски

- Ниша перепродажи Stars/Premium привлекает мошенников под видом "поставщиков" —
  прежде чем заводить в бота реальный API-ключ и переводить USDT, проверьте
  отзывы о FireLoot самостоятельно (Telegram-каналы с отзывами, форумы, возраст
  домена). Мы указали этого поставщика как пример с открытой документацией API,
  но не можем гарантировать его надёжность как контрагента.
- Регистрация ИП/самозанятости для приёма платежей через ЮKassa обязательна по
  закону РФ — без этого работать легально нельзя.
